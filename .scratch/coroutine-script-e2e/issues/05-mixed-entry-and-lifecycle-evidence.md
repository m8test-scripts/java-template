# 05: 验收混合入口、关闭并核对全方法证据

Type: task
Status: claimed

**What to build:** Java 真实脚本证明 Thread/Timer 与协程交替使用及关闭资源安全，并完成本项目公开方法证据核对。

**Blocked by:** 04：验收背压、时间操作与通道清理


## 前置公开能力

- 安全关闭及目标语言最终资源释放能力

能力未具备时不能启动交付；本项目不定义或重建这些通用契约。

## Acceptance criteria

- [ ] 验证嵌套恢复、延迟返回与混合入口，不以偶然线程名代替安全性断言。
- [ ] 分别观察任务取消、回调退出、通知排空与最终协议终态；下一次独立运行仍可成功。
- [ ] 覆盖全部公开及继承方法；原生互操作与无法脚本注入的故障只记录适当边界证据，不冒充 direct-e2e。
- [ ] 通过定向选择用例后执行本项目完整相关集合，保存运行版本、进程身份、报告和缺口。
- [ ] 将公开方法的语义变更纳入逐方法调用证据；本项目只消费公开 API，不复制其定义或添加保留规则。
