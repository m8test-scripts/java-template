# 使用脚本全局变量

从目标项目生成的 BuildScript、变量声明、插件配置或公开文档确认变量名、类型、可用时机和目标语言。变量随宿主、Extension 和模板版本变化，不根据名称或另一语言模板猜测。

- 声明文件、代码补全或依赖已解析只证明静态信息存在，不证明目标引擎运行时已注入对应值或加载其类。
- 优先使用公开全局变量表达的稳定能力，不因实现类恰好在 classpath 中可见而依赖它。
- 当前资料不足时，只读检查变量生成逻辑和公开 API。仅当问题需要当前设备/运行时状态时才生成或查询设备侧数据。
- 修改使用方式时更新受影响语言的 fixture，并执行能证明本次行为的最小验证。
