# 跨 M8Test 仓库工作

先确定本次任务涉及的仓库角色和权威契约来源。优先从当前仓库的 Git 根目录、其祖先中的 M8Test 工作区根，以及同级 `core/`、`extensions/`、`scripts/` 目录推导关联仓库位置；只检查本次需要的仓库，并确认目标目录确实是预期的 Git 仓库。不要扫描无关目录，也不要把推测路径当作已验证路径。

- 优先读取源仓库的公开 API、schema、版本目录与相关文档；实现代码可帮助解释当前行为，但不能自动成为调用方契约。
- 关联仓库默认只读。只有用户授权的任务范围包含该仓库时才修改；被授权的范围优先于默认只读规则。
- 修改跨仓库契约时列出真实生产方和消费方、兼容影响、版本顺序与各自需要的证据。
- 若工作区布局、仓库说明或本地映射无法确定所需仓库的位置，告知用户需要哪个仓库，并请其提供本地路径或 M8Test 工作区根目录；不要求用户预先维护一份共享路径配置，也不猜测个人绝对路径。
- 本地路径映射和设备配置属于各仓库或开发者本机约定；按其实际配置查找，不复制到共享技能或提交内容。
- 检查目标仓库的现有工作区改动，只处理授权文件，保留无关内容。
