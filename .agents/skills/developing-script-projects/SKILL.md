# 开发 M8Test 脚本项目

先确定目标脚本语言、运行时和本次变更位于模板、生成构建层还是实际脚本源码。各语言任务名、源码转换、依赖加载和 JVM 互操作不同，不互相推断。

- 查看目标项目 README、插件配置、生成源码、fixture 与语言专属技能；使用当前仓库实际定义的任务和源目录。
- 区分编辑前脚本、插件生成/转换结果、静态编译结果和设备端引擎执行。上一层成功不能代替下一层证据。
- 修改脚本全局变量时先确认目标模板版本生成的完整名称、类型和可用时机。
- 仅在改动涉及脚本可执行性时选择对应语言/引擎验证；不默认运行设备或全部 Test Control。
- 修改模板行为时检查模板生成后的项目是否仍遵循预期契约。语言专属语法、JVM 转换和构建配置由对应本地技能维护。
